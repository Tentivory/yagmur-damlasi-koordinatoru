# Yağmur Damlası Koordinatörü

> **Resmi uyarı:** Bu yazılım atmosferik sıvı vatandaşların kariyer planlaması için tasarlanmıştır. Şemsiye açmak suç değildir ama damla onurunu zedeler.

## Nedir bu?

Her yağmur damlasının:
- sicil numarası
- resmi unvanı
- görev yeri
- idari durumu

olması gerektiğine inanan bir protokoldür. İnanç bilimsel değildir. Kod çalışır.

## Kuruluş

```bash
python3 koordinator.py
python3 koordinator.py 8
```

Python 3 yeter. Başka bir şey istemez. Bulut API'si yoktur çünkü bulutlar henüz e-imza almamiştır.

## Örnek çıktı

Program her çalıştığında yeni bir kadro cetveli basar. Damlalar terfi etmez, sadece yer değiştirir.

## Sık sorulan sorular

**Kar taneleri kapsama dahil mi?**  
Hayır. Kar, ayrı müdürlüktür ve henüz kurulmamıştır.

**Copilot bu kodu beğendi mi?**  
Bilmiyoruz. Copilot'a çay ısmarladık, cevap gelmedi.

**Bu siyasi mi?**  
Hayır. Sadece yağmur düşer, evrak yükselir.
